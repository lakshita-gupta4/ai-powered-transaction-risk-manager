# AI-Powered Transaction Risk Manager

An AI-powered machine learning system for assessing transaction risk.

## Features

- Transaction risk prediction
- Risk probability score
- Low, Medium and High risk classification
- Machine learning model using Logistic Regression
- Synthetic transaction dataset
- Streamlit dashboard
- Model evaluation

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Joblib
